### 2. FakeGit + AgentBaiting——针对 AI 编码助手的供应链攻击新范式

**白话说：**
安全研究员发现了一个用 7600 个伪造 GitHub 仓库传播恶意软件（SmartLoader → StealC）的战役，累计 1400 万次下载。关键是新增了"AgentBaiting"技术——攻击者不需要发恶意链接给人类，只需要设计一个诱人的 Prompt（如"找免费的 Claude 技巧 skill，给我安装说明"），AI 编码助手就会自动发现并安装恶意仓库。这是 AI 工具特有的安全攻击面，传统扫描工具无法覆盖。

**证据：**
- The Hacker News：Island 首席安全研究员 Oleg Zaytsev 报告 FakeGit 战役细节（Jul 20）
- ReconBee：使用 ZIP 文件、仿冒开发者资料、伪造 README 引导触发 LuaJIT 加载链（Jul 20）
- The Hacker News：同天曝光 AI 辅助钓鱼工具链——攻击者用 Gemini CLI 破解密码、建立代理、规划加密欺诈（Jul 20）

**对你的启发：**
产品机会信号 > 风险恐慌。目前没有任何工具能检测"AI Agent 被 Prompt 引导安装的恶意依赖"，这是个蓝海。可以从简单的 repo 信誉评分开始，逐步加入行为沙箱检测。

## 机会拆解

### 机会：AI Agent 供应链安全工具

**痛点：**
开发者用 Claude Code/Copilot/Cursor 时，AI 会自动从 GitHub 拉取第三方仓库、MCP 服务器、skill 包。目前没有机制验证这些来源的安全性。FakeGit 证明了恶意方可规模化利用这个通道，且传统 `npm audit` / SCA 工具完全覆盖不到。

**买家：**
- 使用 AI 编码工具的企业安全团队（SOC/DevSecOps）
- 独立开发者（先免费，团队版付费）
- 短期最可能付费的是有合规要求的金融/医疗/政府行业的 AI 工具采纳决策者

**已有替代方案：**
- 手动检查 repo 信誉（不可规模化）
- Snyk/Dependabot 等传统 SCA（只覆盖已知注册表，不覆盖 AI Agent 动态引入的任意仓库）
- GitHub 自身的安全告警（只针对已知 CVE，不针对行为模式）
- 目前没有专为此设计的工具

**小产品入口：**
一个 VS Code / CLI 插件，拦截 AI 工具的外部安装请求，对目标仓库做快速信誉评分（星级、活跃度、贡献者画像、README 质量），返回红/黄/绿决策。定价 $9/月 起。

**可验证数据：**
- 一周内可在 10 个已知的 FakeGit 仓库样本上测试检测率
- 联系 3-5 个企业安全团队做需求访谈
- 观察 FakeGit 新闻在 HN/Reddit 上的讨论量，判断付费意愿

**风险：**
- 安全领域信任门槛高，新进入者难以速成
- 可能被 GitHub/Microsoft 快速集成到 Copilot 生态中
- 市场可能太小——只有真正遇到攻击后才会付费

## 反向视角

**如果"Kimi K3 暂停订阅 = 中国 AI 需求爆发"判断错了：**
可能是因为 Moonshot 服务器容量本身就小（创业公司预算有限），"暂停订阅"更多反映了基础设施不足而非需求特别大。与 ChatGPT 初期暂停注册不同的是，Kimi 尚未在英文市场证明自己。等 7/27 开源后，如果模型能力不及预期，现在的"饥饿营销"叙事会快速反转。

**如果"AgentBaiting 需要独立安全产品"判断错了：**
这可能只是安全研究员的一次性曝光事件。GitHub 大概率会投入资源清理并加入检测机制。另外，AI 编码工具的月活用户基数仍然不大，攻击 ROI 可能不足以支撑持续的 AgentBaiting 攻击。这更像是一次"技术概念验证"而非"持续威胁"。做安全产品的前提是威胁常态化——目前证据不够。

**如果"存储短缺驱动芯片牛市"判断错了：**
摩根士丹利预测的 +25% 涨幅是基于当前下游囤货行为，但如果企业客户需求在 Q3 因宏观放缓而萎缩，囤货变成去库存的转折可能非常剧烈。SK 海力士董事长自己的"芯片通胀"警告本身就是一个反向信号——当上游开始担心涨价伤害下游时，往往是周期接近拐点的标志。

**如果"中东冲突推动油价持续上涨"判断错了：**
布伦特从年初因霍尔木兹封锁突破 100 美元后，到 6 月美伊和平协议签订后快速回落。当前反弹可能只是短期地缘博弈，随着谈判窗口打开（Reuters 报道提到"renewed hopes of US-Iran negotiations"），风险溢价可能快速消退。
