### 机会 B：模型切换 / 多云适配中间件

**痛点：** Anthropic 事件让开发者意识到：依赖单一美国闭源模型的业务随时可能被切断。但切换模型不是改一行 API key 那么简单——prompt 行为、输出格式、成本结构都不同。

**买家：** 国内正在使用 OpenAI/Anthropic API 的中小 SaaS 团队。他们付不起专职 ML 工程师做迁移，但禁不起突然断供。

**已有替代方案：** LiteLLM、OpenRouter 提供基本的模型路由，但缺少"出口管制合规检查"这一层。

**小产品入口：** 做一个开源中间件，在 LiteLLM 基础上加一层"合规检查 + 自动降级"——当检测到某个模型受控时，自动切换到国产替代并评估兼容性。

**可验证数据：** 在 V2EX/即刻发帖"如果 Anthropic 明天禁了中国 IP，你的产品怎么办？"，收集反馈。

**风险：** 大厂（阿里云/腾讯云）正在做类似的事，小团队窗口期可能很短。同时，如果出口管制放松，需求会立刻蒸发。

## 反向视角

**为什么"Anthropic 出口管制 → 国产 AI 利好"这个判断可能不成立：**

1. **管制可能只是谈判筹码**：如果特朗普政府以管制为谈判工具，随时可能松动。历史上有多次"先禁后放"的案例。

2. **反而加速美国模型闭源化**：如果美国 AI 公司因为管制压力变得更加封闭（只在美国境内提供服务），全球开发者生态可能受损，长期对中国 AI 生态也不利——开源模型依赖全球社区贡献。

3. **DeepSeek 不一定是受益者**：DeepSeek 刚融资 510 亿，估值压力巨大。如果出口管制推高了"国产替代"的期待，反而可能产生过高的业绩预期。

4. **市场已经在定价**：AI 算力/半导体板块昨日（6/18）已大涨——恒指 +3.09%，科指 +5.22%，算力概念股涨幅惊人（利通电子 +562% YTD），利好可能已部分释放。
