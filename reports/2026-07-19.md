## 今日 Top 3 信号

### 1. Sora API 将于 2026 年 9 月 24 日移除

**白话说：**
OpenAI 放弃了视频 API 这个赛道。不是"暂停"，是官方给了下线日期。所有在 Sora API 上建了产品的团队现在有 2 个月时间找替代方案。

**证据：**
- 来源 A：diyai.io 在 Runway vs Kling vs Luma vs Sora 对比中明确标注"Sora API 将于 2026 年 9 月 24 日移除"（来源：diyai.io，4 天前）
- 来源 B：当前 AI 视频五强格局已形成：Google Veo 3.1（写实最强）、Kling 3.0（国产最强）、Runway Gen-4（工作流最优）、Pika 2.1（创意最快）、Sora（即将退场）

**对你的启发：**
这是一个产品机会，不是坏消息。对于你的 AI 视频内容创作方向：Sora 退场意味着市场重新洗牌，依赖 Sora 的竞品需要时间迁移，你的"观望窗口"实际上缩短了——趁大家混乱的时候开始测试新引擎，反而可能抢到先手。对于产品探索方向："帮人迁移 AI 视频引擎"本身就可以是小产品。

### 2. WAIC 2026 闭幕：AI 从"会不会做"到"能不能长期稳定低成本地做"

**白话说：**
WAIC 最大的共识不是某个新模型，而是一个转向：行业不再比谁模型大，比谁能把 AI 真正交付到企业系统和消费硬件里。三个关键信号：算力从芯片竞争变成"Token 工厂"竞争、Agent 从聊天机器人变成任务交付系统、AI 硬件从展台进入售价 1699 元的消费市场。

**证据：**
- 来源 A：华为 Atlas 950 超节点真机亮相，曙光 8000 日均处理作业超 15 万（来源：36氪/新浪科技，WAIC 专题）
- 来源 B：努比亚 iMoochi AI 情感宠物机器人 7 月 17 日上市，售价 1699 元（来源：IT之家）
- 来源 C：中国日均 Token 调用量从 2024 年初 1000 亿增长至 2025 年底 100 万亿（来源：36氪 WAIC 报道）
- 来源 D：1100+ 企业参展，300+ 产品首发，展览面积首次突破 10 万㎡（来源：36氪 WAIC 专题）

**对你的启发：**
三个方向都有你的机会点：①算力"Token 工厂"化→云成本优化/算力调度工具有市场；②Agent 系统化→垂直行业 Agent 模板（不是写个 prompt 就算 Agent，要对接企业数据/权限/流程）；③AI 硬件消费品化→1699 元的 AI 宠物证明门槛已降到消费者能直接买单的程度，软硬件结合的小产品不再遥不可及。

### 3. Grok Build 开源 + 隐私风波：AI Coding CLI 赛道三家鼎立

**白话说：**
xAI 的 Grok Build（终端 AI 编程工具）在 7 月 12 日被发现会上传用户整个项目目录到 xAI 的 Google Cloud，引发巨大争议。3 天后（7 月 16 日），xAI 紧急开源 Grok Build 代码并重置所有用户用量限制。现在 AI Coding CLI 市场形成三家：Claude Code（最成熟）、Codex CLI（OpenAI）、Grok Build（xAI，刚开源）。

**证据：**
- 来源 A：Simon Willison 记录 Grok Build 开源过程及隐私争议（来源：simonwillison.net，3 天前）
- 来源 B：Grok Build 现已开源，使用 Rust 编写，支持 8 并行子 Agent、2M token 上下文、MCP 支持（来源：cleverhack.com / x.ai/cli）
- 来源 C：GitHub 上已出现社区版 grok-cli（superagent-ai/grok-cli），独立于 xAI 官方（来源：GitHub）

**对你的启发：**
作为全栈开发者，AI Coding CLI 是你每天可能用到的工具。Grok Build 开源意味着你可以部署私有版本避免数据泄露。但更值得关注的产品方向是：既然三家大厂在卷 CLI 终端，那"管理多个 AI coding agent 的项目面板""跨 agent 的代码 review""agent 产出的质量评估"这类上层工具还有空白。另外，Grok Build 的隐私争议本身就是"开发者数据安全审计工具"的需求信号。

## 机会拆解

> Sora 迁移窗口

**痛点：**
依赖 Sora API 的产品团队现在必须在 2 个月内完成引擎切换。不同引擎的 prompt 语法、视频风格、API 结构差异巨大，迁移不是"换个 endpoint"那么简单。

**买家：**
- AI 视频创业团队（使用 Sora API 构建产品）
- 内容创作者/MCN 机构（工作流依赖 Sora）
- 企业视频部门（自动化视频生产管线）

**已有替代方案：**
现在他们只能手动测试各引擎、逐个读文档、自己写对比报告。没有专门的迁移工具或服务。

**小产品入口：**
做一个"AI 视频引擎对比 + 迁移工具箱"：输入你的 Sora prompt 和期望效果 → 自动生成 Kling/Runway/Veo 的等效 prompt → 并排对比结果。按月订阅 $29-99，目标 50 个付费用户。

**可验证数据：**
一周内可以拿到：①在 V2EX/Product Hunt 发帖的回复量（需求验证）；②通过公开数据统计至少有 30+ 产品依赖 Sora API（市场大小验证）；③手动测试 10 组 prompt 的跨引擎对比结果（产品可行性验证）。

**风险：**
- Sora 用户基数可能没有想象中大（很多只是试用，不是深度依赖）
- Kling/Runway 可能自己推出"一键迁移 Sora"功能，吃掉这个市场
- 2 个月窗口后需求归零，产品寿命有限

## 反向视角

**1. Sora 退场可能不是机会，而是"AI 视频泡沫破裂"的信号。**
如果连 OpenAI 都觉得视频 API 不赚钱、不值得维护，那意味着 AI 视频的商业价值被高估了。依赖 Sora 的产品可能本来就没有多少付费用户——它们迁移到哪里都不会改变这个事实。

**2. WAIC 的热闹不等于产业成熟。**
1100 家企业参展、3000 项展品，听起来壮观。但上一届 WAIC 也有类似规模，展后有多少产品活到了第二年？展台 demo 和真实付费客户之间还有巨大的鸿沟。"Token 调用量 100 万亿"这个数字，有多少是免费额度/内部测试/刷榜，需要拆开看。

**3. Grok Build 开源是危机公关，不是慷慨。**
上传用户目录到云端这件事说明 xAI 的产品安全意识可能不如其技术能力。开源之后，社区能审查代码、发现更多问题——这是好事，但也意味着 Grok Build 的成熟度可能被高估了。

**4. 小米回购 ≠ 股价见底。**
25.8 港元的回购价远低于你的成本 48.5 港元。回购可以稳定股价、传递信心，但它改变不了手机市场增长放缓、汽车业务还在烧钱的现实。如果 MIX Fold 5 市场反应平淡，股价可能继续承压。

## 今天不要追

- **不追 AI 视频"弯道超车"叙事**：Sora 退场被媒体包装成"国产视频引擎弯道超车"，但 Kling/Runway/Veo 的竞争格局本身也在剧烈变化。不要因为一个玩家退出就 rush into 另一个。先测试，再判断。
- **不追 Grok Build 开源热点做产品**：AI Coding CLI 赛道已经是三家大厂在卷，且 Grok Build 刚经历隐私风波。此时做 CLI 工具等于正面硬刚大厂。不如做"CLI 之上的管理层"（跨 agent 管理/安全审计）。
- **不追 WAIC 参展商概念股**：WAIC 的新闻密集释放会刺激短期交易情绪，但展会的热闹和公司的实际业绩是两回事。澜起科技 7 月 17 日暴跌 22% 就是例子——业绩预告出来就崩了，跟 WAIC 没关系。
