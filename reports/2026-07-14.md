**周末能扩成什么：**
一个 VS Code 插件 MVP：右键 AI 生成的代码块 → "AI 代码审查" → 用 Claude API 做安全 + 质量扫描 → 输出行级标注。首周免费，之后 $9/月。

### 2. AI Agent 工具正在从「编码助手」变成「通用办公代理」

**白话说：**
上周 AI Agent 领域出现密集升级：Claude Cowork 从桌面扩展到手机和网页，Claude Code 桌面版内置沙箱浏览器能直接操作网页，Cursor 被曝在开发面向非开发者的通用 Agent "Sand"。AI 不再只是帮你写代码——它正在接管浏览器操作、邮件处理、文档工作。这对开发者既是机会（做 Agent 垂直应用），也是威胁（Agent 会替代很多简单工具产品）。

**证据：**
- Claude Code Desktop v2.1.202-206（7/6-10 发布）新增沙箱浏览器，Agent 可打开网页、点击、读取（来源：Digital Applied）
- Claude Cowork 扩展到移动端和 Web，任务可跨设备接力（来源：TechCrunch, 7/7）
- Cursor 正开发代号 "Sand" 的通用 AI Agent，目标非开发者市场，与 Claude Cowork 正面竞争（来源：The Information / LLM Stats）
- Anthropic 发布 Claude Fable 5 模型（来源：Product Hunt）

**对你的启发：**
你是全栈开发者，最应该关注的是 Agent 工具链中的「缝隙」——Claude 和 Cursor 在抢平台，但垂直场景的 Agent 工具（比如专门做小红书内容排期 + AI 生成的 Agent、专门做独立开发者财务报表的 Agent）还远没有饱和。这和你的 AI 穿搭账号也能结合。

### 3. npm 供应链攻击升级：jscrambler 被植入 Rust 窃密程序

**白话说：**
npm 包 jscrambler 8.14.0 版本被入侵，安装时会运行一个 Rust 写的窃密程序，扫描开发者机器上的密钥和敏感文件，通过 TLS 发送到攻击者服务器。同时 CISA 新增了两个 Joomla 零日漏洞到已知利用漏洞目录。这是本周内第二起重大供应链安全事件。

**证据：**
- jscrambler 8.14.0 被植入跨平台（Win/Mac/Linux）Rust infostealer（来源：The Hacker News / Socket）
- CISA 将 iCagenda 和 Balbooa Forms Joomla 漏洞加入 KEV 目录（来源：The Hacker News）
- 上周 ShareFile 存储控制器被紧急关闭（来源：SecurityWeek）

**对你的启发：**
如果你在开发中使用 npm 生态，这是本周内第二起供应链安全事件，趋势明显在恶化。建议：① 在项目中使用 `npm audit` + lockfile 严格管理，② 不要盲目信任 AI 生成的 `npm install` 命令——AI 可能推荐已被入侵的包。

## 反向视角

**为什么今天的 A 股暴跌可能不是趋势逆转：**

1. **地缘事件驱动的下跌通常短期消化**：霍尔木兹海峡冲突历史上多次发生，市场通常在 1-2 周内定价完毕。Trump 6 月就曾威胁打击伊朗后又取消（"TACO 交易"），这次也可能类似。

2. **成交量 2.83 万亿说明有承接**：不是无量下跌，说明市场分歧大而非一致看空。真正恐慌性抛售往往伴随缩量。

3. **科技/AI 的基本面没有恶化**：OpenAI 刚发布 GPT-5.6，WAIC 上 300+ AI 新品首发，Meta 资本开支指引 1250-1450 亿美元——AI 投入还在加速。你的科创和双创 ETF 的底层逻辑没有实质变化。

4. **港股实际上涨 0.16%**：如果 A 股的问题是系统性危机，港股应该同步下跌。港股微涨说明这更像是 A 股自身的获利回吐 + 情绪释放。

**但需要注意的风险：**
- 如果美伊冲突升级为实际军事行动（非口头威胁），油价可能进一步飙升，对全球风险资产都是系统性打击。
- 赛力斯刚公告 H1 预亏 15-18 亿（转亏），说明新能源/汽车链的成本压力在上升——这可能波及其他制造业。

## 今天不要追

- **不追 1：不要在大跌日恐慌性减仓科技 ETF**。持仓逻辑没变，单日情绪驱动的下跌不应触发交易决策。但如果美伊局势本周内持续升级，可以考虑减少科技板块仓位——下周再判断。
